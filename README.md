# LLMTalkMAnager

Локальный голосовой агент на базе Pipecat, использующий Faster-Whisper для STT, Ollama для LLM и Silero для TTS. Репозиторий содержит минимальную сборку сервисов для запуска on-premise пайплайна с низкой задержкой.

## Архитектура
- **Transport (Daily WebRTC)** — принимает и отдает аудио потоки; настроен на 16 kHz вход и 24 kHz выход.
- **VAD (Silero)** — генерирует события начала/конца речи; триггерит отправку накопленного аудио на распознавание.
- **STT (Faster-Whisper)** — буферизует аудио между событиями VAD, выполняет инференс в пуле потоков, публикует `TranscriptionFrame`.
- **LLM (Ollama)** — наследует OpenAI-совместимый сервис Pipecat и отправляет запросы на локальный Ollama сервер с расширенными параметрами контекста.
- **TTS (Silero)** — синтезирует речь по предложениям, полученным от SentenceAggregator, и возвращает сырые PCM16 байты.

## Быстрый старт
1. Установите зависимости Pipecat и модели Faster-Whisper, Silero TTS, Ollama.
2. Задайте переменные окружения `DAILY_ROOM_URL` и `DAILY_TOKEN`.
3. Запустите бота:
   ```bash
   python bot.py
   ```

## Обработка ошибок и логирование
Все сервисы содержат подробное логирование и перехват исключений, чтобы легче отлаживать локальный пайплайн. Фатальные ошибки пробрасываются после записи в лог, что позволяет рантайму корректно завершить выполнение.
